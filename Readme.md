#　ササメ
Gemini APIを使った、AIチャットボットです.


## 使用技術
- Backend: Python, Flask
- AI: Gemini API (gemini-3.5-flash-lite)
- Frondend: HTML / CSS / JavaScript
- Deploy: Render

## 機能
- キャラクター性を持ったAIとの会話
- 会話記録の保持(JSONL形式)
-　APIエラー時の自動リトライ

## 工夫した点
- JSONではなくJSONLを採用
　会話記録を保持する際に前回の記録に今回の記録を追記するため、配列で囲まずに一行ずつ追記できるJSONLを採用した。
- sendBtn.disabled = trueをつかった連続送信の対策
- finallyにsendBtn.disabled = false;をいれた、成功・失敗どちらで終わっても次につながる処理
- chatWindow.scrollTop = chatWindow.scrollHeight;によって最新のメッセージを常に表示。

## 開発について
本プロジェクトはAIアシスタント(Claude)とのペアプログラミングで開発しました。コードの生成や実際に発生したエラーを調査・検証しながら解決しています。
# 実際に発生したエラー
- 綴り違い、引数不足、キーの食い違い
- 追記によるJSONエラー
- ルーティングミス

## 苦労した点・学んだこと
関数はなるべく役割ごとに分ける。一つの関数で一つの仕事をするのがベスト。
エラーの種類を区別することが大事。これのおかげでエラー時にリトライするかどうかの区別もできる。
空のメッセージを最初に弾くことで無駄な消費をしないで済むということ。
エラーは種類によって別々のステータスを返すことで、検証しながら進めることができた。
